Si te fillojme projektin :

Ne Terminal shkruaj

1. cd backend
2. node index.js

Prite mesazhin : Backend started on port http://localhost:3000

Dhe ke filluar back-endin.

Pastaj ne nje terminal te ri shkruaj:

3. cd frontend
4. cd loginow
5. npm run dev

Dhe eshte startuar edhe frontend ne portin 5173.
